## Categories

Six categorical tones tell groups apart, such as the categories in a vocabulary. They stay distinct with protanopia, deuteranopia and tritanopia. `dataTone(index)` picks one, and repeats after six.

<Preview
  code={`{categories.map((name, index) => <Badge tone={dataTone(index)}>{name}</Badge>)}`}
>
  {["people", "setting", "time-of-day", "weather", "room", "style"].map(
    (name, index) => (
      <Badge tone={dataTone(index)}>{name}</Badge>
    ),
  )}
</Preview>

The same colours are Tailwind utilities, such as `bg-data-2` for a bar or `border-data-4` for an edge. Always pair them with text: colour alone doesn't say which group is which.
